# TunboxSub

TunboxSub 是由 `yhxi` 维护的 HarmonyOS NEXT 二次开发项目，基于 [xiaoli8571/TunBox v0.8.9](https://github.com/xiaoli8571/TunBox/tree/fa6c9eb9a568198872f71a87bb2db684f883aa69)。感谢上游项目及其贡献者。

本项目目前聚焦桌面服务卡片与 VPN 通知栏的状态同步。测试版 HAP 见 [GitHub Releases](https://github.com/yhxi/tunboxsub/releases)。

发布资产是未签名 HAP，需使用适配目标设备的开发签名后安装。内置 mihomo 内核的对应源码和许可信息见 [内核源码](https://github.com/xiaoli8571/TunBox/tree/fa6c9eb9a568198872f71a87bb2db684f883aa69/mihomo-build) 和 [第三方声明](https://github.com/xiaoli8571/TunBox/blob/fa6c9eb9a568198872f71a87bb2db684f883aa69/TunBox_HarmonyOS/THIRD_PARTY_NOTICES.md)。
